**# Vowel and Consonant Counter**



**## About the Project**

**The \*\*Vowel and Consonant Counter\*\* is a web application developed using Django. It counts the number of vowels and consonants present in a user-entered sentence.**



**The application takes a sentence as input, processes the text, and displays the total number of vowels and consonants.**



**## Features**

**- Accepts a sentence from the user.**

**- Counts vowels (A, E, I, O, U).**

**- Counts consonants (all other English alphabet letters).**

**- Displays the total number of vowels and consonants.**

**- Simple and user-friendly interface.**



**## Technologies Used**

**- \*\*Python\*\* – Programming language**

**- \*\*Django\*\* – Web framework**

**- \*\*HTML\*\* – Web page structure**

**- \*\*CSS\*\* – Styling and layout**



**## How It Works**

**1. The user enters a sentence in the input field.**

**2. The application processes each character in the sentence.**

**3. It checks whether each alphabet character is a vowel or a consonant.**

**4. It counts the vowels and consonants separately.**

**5. The results are displayed on the web page.**



**## Example**



**\*\*Input:\*\***

**```text**

**Hello World**

**```**



**\*\*Output:\*\***

**```text**

**Number of Vowels: 3**

**Number of Consonants: 7**

**```**



**## Installation and Setup**



**### 1. Clone the Repository**

**```bash**

**git clone <your-repository-url>**

**```**



**### 2. Open the Project Folder**

**```bash**

**cd <project-folder>**

**```**



**### 3. Install Django**

**```bash**

**pip install django**

**```**



**### 4. Run Database Migrations**

**```bash**

**python manage.py migrate**

**```**



**### 5. Start the Development Server**

**```bash**

**python manage.py runserver**

**```**



**### 6. Open the Application**

**Visit the following URL in your browser:**



**http://127.0.0.1:8000/**
